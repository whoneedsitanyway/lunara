# Концепт: кассетный лупер «TAPE»

> Статус: **идея, не реализовано.** Файл фиксирует концепт, чтобы не потерять.
> Реализация отложена до отдельного решения.

## Идея

Под осциллографом (`WaveDisplay` внизу педали) напрашивается **кассетный лупер**:
визуально — кассета с двумя бобинами и окном плёнки, функционально — зацикливание
входного сигнала с транспортом как у кассетного плеера (play / stop / перемотка /
питч-скорость). Это превращает Lunara из «облака по входу» в **сэмплер-в-облако**:
записал фразу — гранулятор и реверб бесконечно её мнут.

Метафора кассеты естественно даёт:

- **плёнка** = петля (loop), **головка** = позиция воспроизведения;
- **бобины** крутятся с реальной скоростью и направлением (из позиции/длины петли);
- **varispeed** — реальная фишка кассет: замедление плёнки = питч вниз, ускорение = вверх;
- **перемотка** даёт характерный «скрэтч»-звук на скорости.

## Транспорт (моментальные кнопки, не тумблеры)

- ⏺ **REC** — писать вход в петлю (запись / overdub).
- ▶ **PLAY** — петля играет.
- ⏸ **STOP** — стоп.
- ◀◀ **REW** / ▶▶ **FF** — перемотка головки (скрэтч на скорости).
- 🎚 **VARISPEED** — скорость/питч плёнки.

## Позиция в сигнальной цепочке (варианты)

Текущая цепь: `in → GRAINS → DELAY → SPACE → OUT`.

| Вариант | Как звучит | Сложность |
|---|---|---|
| **A. TAPE как источник** (перед гранулятором) | Записал фразу → гранулятор бесконечно её перемалывает. Лучше всего под характер плагина | средняя |
| **B. TAPE как вставка** (после reverb, перед output) | Лупер-«финишер», копит готовый текстурный саунд | низкая |
| **C. TAPE в параллель**, отдельный слой | Петля + живой облачный сигнал одновременно | средняя |

**Рекомендация — вариант A**: расширяет уже существующий переключатель
**FX SOURCE** (`IN / OUT / BOTH`) четвёртым значением `TAPE` и естественно
ложится на текущую коммутацию эффектов.

## DSP (по образцу существующих `Source/dsp/*.h`)

Новый header-only `Source/dsp/TapeLooper.h` в стиле `GrainEngine` / `SyncDelay`:

- кольцевой буфер на N секунд (моно/стерео), запись головкой;
- голова чтения с **плавным varispeed** (`pos += speed`), интерполяция как в
  `readInterpolated` (кубическая Catmull-Rom);
- **overdub** — старая петля + новый вход × feedback;
- **reverse** — просто отрицательная скорость;
- **клик-фри** стоп/старт/перемотка (короткие fade-рампы);
- **санитайз нефинитных** значений и клампы позиций чтения/записи (по тем же
  принципам, что закладывались в защиту остальных модулей).

## Параметры (в стиле APVTS проекта)

```
tapeMode     choice  {Off, Rec, Play}        — транспорт
tapeSpeed    float   -2.0 .. 2.0   (1.0)     — varispeed (октавы вниз/вверх)
tapePitch    float   -12 .. 12 st  (0)       — питч независимо (опционально)
tapeLen      choice  {Free, 1/1, 2/1, 4/1}   — длина петли, синхронна к BPM
tapeFeedback float   0..1                    — overdub / насыщение петли
tapeMix      float   0..1                    — доля петли в сигнале
```

Длину петли синхронизировать через уже существующие `currentBpm` и `kDivisions` —
петли встают в сетку хоста (для эмбиента критично).

## UI (`CassetteComponent`)

- рисуется в `vizArea` вместо / рядом с `WaveDisplay`; waveform петли оверлеится
  в окно кассеты;
- бобины: угол поворота из `loopPos` / `loopLen` и знака `speed`;
- транспорт — ряд моментальных кнопок под кассетой;
- в `timerCallback` читаем из процессора атомики по тому же паттерну, что
  `displayBpm`: `tapePos`, `tapeLenSec`, `tapeRecording`, `tapePlaying`.
