# Roadmap

## Сделано (v1.0.0)

- [x] Каркас CMake + JUCE 8, форматы VST3 / AU / Standalone.
- [x] Гранулярный движок: size, density, spray, jitter, reverse, стерео-разброс.
- [x] Pitch ±12 st с режимами Quantize / Smooth (дрейф — отдельно, см. Drift).
- [x] Sync-delay: BPM-синк, деления, фидбэк, ping-pong, tone в петле.
- [x] Cloud reverb: FDN + диффузия + модуляция + cloud smear.
- [x] Выходной каскад: лимитер (вкл/выкл), low-cut HPF, output.
- [x] Глобальный dry/wet (Mix).
- [x] 6 режимов-характеров.
- [x] Кнопка Random (`randomizeParameters()`), перенесена в хедер педали.
- [x] Pedal-style UI: корпус, винты, нобы Microcosm-стиля.
- [x] Осциллограф `WaveDisplay`: вход поверх выхода + тайминги (BPM/деление/мс).
- [x] Зум видимого окна в тактах (0.5 / 1 / 2 / 4) + прогресс 5 сек.
- [x] Параметр и ручка **CHAOS** (музыкальная расстройка и артефакты).
- [x] Компактный режим (COMPACT / FULL) со скрытием осциллографа.
- [x] Единый стиль кнопок MODE / RANDOM / COMPACT, исправлены наложения.
- [x] Цвета визуализации: оригинал — accent, обработка — полупрозрачная.
- [x] Оптимизация: децимированная огибающая scope + лёгкий DSP.
- [x] Устойчивость: сатураторы в петлях, DC-блокер, NaN-защита, стресс-тест.
- [x] Индикатор gain reduction + CLIP-LED; волна выше и растянута по вертикали.
- [x] MODE без подписи, в один размер с кнопками RANDOM / COMPACT.
- [x] Английские подсказки при наведении; исправлены наложения (винты).
- [x] SYNC перенесён вправо от DIVISION.
- [x] Random не трогает Mix и Chaos.
- [x] Tone — 2-полюсный ФНЧ (12 дБ/окт), диапазон 60..18000 Гц.
- [x] Нулевая задержка (`setLatencySamples(0)`) и микро-оптимизации буферов.
- [x] Счётчик FPS в визуализации.
- [x] Система пресетов: сохранение/загрузка, иконка Save, стиль как Mode.
- [x] Светлая / тёмная тема (мягкая светлая), переключатель и сохранение выбора.
- [x] Round-trip тест пресетов (`Tests/PresetTest.cpp`).
- [x] Дефолты: Mix 0.3, Tone 18000 Гц (макс.), режим Bloom.
- [x] Фикс «шума»: нормировка грейнов по перекрытию + пик-теймер, нормировка
      инжекта реверба + ВЧ-фильтр, ограничение фидбэка, кламп длины линий.
- [x] FPS визуализации поднят (таймер 90 Гц, останавливается в COMPACT).
- [x] **Auto Gain** (галочка в OUTPUT): RMS-компенсация потерь уровня.
- [x] Ping-Pong усилен (моно-инжект при максимуме — эхо прыгает L/R).
- [x] Cloud усилен (каскад all-pass) и Reverb стал отчётливее слышен.
- [x] **Исправлен баг реверба**: инвертированный коэффициент ВЧ-фильтра инжекта
      вырезал ~99.9 % сигнала — реверб почти молчал. Теперь `send=1` даёт ~0.5
      от уровня сухого сигнала.
- [x] Auto Gain перенесён в одну строку с лимитером.
- [x] Drift: медленный tape-like питч-дрейф (wow/flutter) вместо дёрганой расстройки.
- [x] Гранулярные эффекты усилены (spray ×5, стерео-разброс/jitter выше).
- [x] Auto Gain: шире диапазон/быстрее; ручка OUTPUT блокируется при включении.
- [x] **HALF TIME**: всё в два раза медленнее (граны −12 st, дилей ×2, реверб глубже).
- [x] **Чёрный ящик `DebugLogger`**: lock-free снапшоты уровней по каскадам,
      heartbeat и автовыгрузка истории при аномалии в `lunara_debug.log`.
- [x] Кнопка-иконка **LOG** (открыть журнал) + красный индикатор аномалии.
- [x] **Фикс «громкости в небеса»**: Auto Gain/Output перенесены ПЕРЕД лимитером
      (лимитер снова последний каскад), финальный кламп ±1.0 и детект конечного
      разгона (раньше ловился только NaN/Inf).
- [x] Финальная чистка: убраны deprecated/неиспользуемые члены и include; таймер
      визуализации останавливается в COMPACT; документация синхронизирована.
- [x] Тесты: авто-гейн, дрейф (`Tests/DriftTest.cpp`), half-time
      (`Tests/HalftimeTest.cpp`) и защита от разгона + логгер
      (`Tests/RunawayTest.cpp`).
- [x] Фикс светлой темы: подписи нобов и текст кнопок/комбо были «зашиты» при
      создании и оставались белыми — теперь цвета пересчитываются при смене темы
      (`refreshThemedColours()`), тест `Tests/ThemeRenderTest.cpp`.
- [x] Значения параметров в UI показываются ≤ 4 знаков (хвостовые нули убраны),
      тест `Tests/ParamFormatTest.cpp`.
- [x] **FX SOURCE** (по мотивам Chase Bliss MOOD MK2): отдельная кнопка в хедере
      переключает, что обрабатывают эффекты — `IN` (вход) / `OUT` (облако,
      дефолт) / `BOTH`; гранулярное облако всегда звучит параллельно. Раньше
      эффекты стояли после гранулятора, и CLOUD почти не «цеплял» вход.
      Тест `Tests/FxSourceTest.cpp`.
- [x] Тёмная тема: приглушены рамка и цифры полей значений нобов (были
      ярко-белыми из-за дефолтного LookAndFeel до привязки к палитре);
      регресс-проверка в `Tests/ThemeRenderTest.cpp`.
- [x] **Заводские пресеты**: вшиты в плагин (`Source/FactoryPresets.h`),
      устанавливаются в пользовательский каталог при первом запуске; при
      открытии свежего экземпляра выбирается и применяется **`Play with Me`**
      (восстановленный проект не перезаписывается). Тест
      `Tests/FactoryPresetTest.cpp`.
- [x] **Выходной каскад упрощён**: выбор `Limit / Clip / Limit+Clip` заменён
      галочкой **Limiter** (вкл/выкл) рядом с Auto Gain; режимы Clip убраны.
      Класс `LimiterClipper` переименован в `Limiter`, добавлен мягкий потолок.
- [x] **HPF-ручка** (вместо ручки `DRIVE`): low-cut 2-го порядка **20..500 Гц**
      (дефолт 100 Гц) на выходе, с плавным глайдом частоты; убирает
      низкочастотную «кашу» от большого `REVERB`/`DELAY`. Тест
      `Tests/HpfTest.cpp`.
- [x] **Проход по багам и оптимизации**: глайд времени дилея и размера реверба
      (нет щелчков при смене деления/SIZE), мягкий потолок лимитера, кубическая
      интерполяция грейнов, Hann-окно из таблицы, ветвления вместо `%` в
      дилее/ревербе, единый `setSize` буферов за блок.
- [x] **Обновлены заводские пресеты** (значения `hpf`), версионированная
      переустановка (`factory_version.txt`) — при обновлении пресеты в
      пользовательской папке обновляются.
- [x] UI-фиксы: иконка луны (тёмная тема) больше не вылезает за кнопку и не
      стирает её рамку; кнопки зума осциллографа `+` / `−` читаемы в светлой теме
      (тёмный фон на тёмном экране); текст чекбоксов OUTPUT читаем в светлой теме.
- [x] **Freeze** — галочка в секции OUTPUT рядом с Limiter/Auto Gain: удерживает
      гранулярное облако (вход в кольцевой буфер не пишется), поэтому текстура
      тянется бесконечно даже при тишине на входе. Тест `Tests/FreezeTest.cpp`.
- [x] Документация в `./doc`.
- [x] Валидация AU (`auval`).
- [x] **REVERSE** — галочка в GRAINS (рядом с Pitch Mode): все граны играют
      назад (100% reverse); тест `Tests/StretchReverseTest.cpp`.
- [x] **STRETCH** — галочка в OUTPUT (рядом с Freeze): плавно (~0.6 с) переводит
      всю цепь в длинную PaulStretch-подобную текстуру (size→500 мс, density→120,
      spray→1, feedback→0.93, реверб/decay/cloud→max, drift +0.6) и так же плавно
      возвращает; тест `Tests/StretchReverseTest.cpp`.
- [x] **Подготовка релиза 1.0.0**: версия в CMake и в шапке UI; tail length 12 с
      (хвосты STRETCH не обрезаются при офлайн-рендере); кэш raw-параметров
      (без строковых лукапов в audio-потоке); счётчик активных грейнов; пути
      осциллографа без аллокаций; CMake-хелперы для тестов; удалён устаревший
      отладочный `ReverbProbe`; добавлен `.gitignore`.
